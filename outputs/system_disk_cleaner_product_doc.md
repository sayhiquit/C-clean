# 系统盘文件识别与清理工具产品文档

## 1. 产品概述

产品名称：System Disk Cleaner

产品定位：一款面向 Windows 系统盘的文件识别、归类、风险评估与安全清理工具。它不直接把“看起来没用”的文件删除，而是先判断文件来源、用途、风险等级和可恢复性，再引导用户进行安全清理。

核心目标：
- 识别系统盘中文件属于系统文件、软件产生文件、用户文件、缓存/临时文件、未知文件中的哪一类。
- 帮助用户理解哪些文件可以安全清理，哪些需要谨慎处理，哪些禁止删除。
- 提供清理前备份、回滚、日志记录和白名单保护，降低误删风险。

核心原则：
- 系统关键文件默认不可删除。
- 未知文件默认不建议删除。
- 清理动作必须可预览、可确认、可回滚。
- 工具优先做“安全建议”，不做激进自动删除。

## 2. 目标用户

主要用户：
- 普通 Windows 用户：系统盘空间不足，希望知道哪些文件可以清理。
- 运维/技术支持人员：需要快速判断系统盘中文件来源和风险。
- 软件测试人员：需要识别某些软件安装、运行后产生的残留文件。

非目标用户：
- 希望绕过系统权限强制删除系统文件的用户。
- 希望修改 Windows 核心组件、驱动、注册表关键项的高风险场景。

## 3. 核心场景

场景一：系统盘空间不足
用户打开工具，选择系统盘扫描。工具展示可安全清理的临时文件、安装缓存、浏览器缓存、日志文件等，并说明预计释放空间。

场景二：卸载软件后清理残留
用户选择“按软件来源查看”，工具展示某个软件可能遗留的目录、日志、缓存和配置文件，用户可以保留配置，只清理缓存。

场景三：判断陌生文件是否可删
用户搜索某个文件或路径，工具根据文件签名、路径、权限、创建时间、数字签名、安装包信息、进程占用等信息给出分类和风险提示。

## 4. 文件分类规则

### 4.1 系统文件

定义：Windows 系统运行、启动、更新、驱动、安全组件所依赖的文件。

常见路径：
- `C:\Windows`
- `C:\Program Files\WindowsApps`
- `C:\ProgramData\Microsoft`
- `C:\Recovery`
- `C:\System Volume Information`
- `C:\$Recycle.Bin`

识别依据：
- Windows 受保护系统路径。
- Microsoft 数字签名。
- 被系统服务、驱动、计划任务引用。
- 属于 Windows 更新、WinSxS、驱动仓库、启动组件。

默认策略：
- 标记为“系统文件”或“系统保护文件”。
- 默认禁止删除。
- 只允许跳转到 Windows 官方清理入口，例如磁盘清理、存储感知、Windows Update Cleanup。

### 4.2 软件产生的文件

定义：第三方软件安装、运行、更新、缓存、日志、插件、崩溃报告产生的文件。

常见路径：
- `C:\Program Files`
- `C:\Program Files (x86)`
- `C:\ProgramData`
- `C:\Users\{User}\AppData\Local`
- `C:\Users\{User}\AppData\Roaming`
- `C:\Users\{User}\AppData\LocalLow`

识别依据：
- 安装程序注册表项。
- 卸载信息中的 DisplayName、Publisher、InstallLocation。
- 文件数字签名和公司名。
- 目录命名与软件名称匹配。
- 文件最近访问时间、修改时间、大小和扩展名。
- 软件运行进程、服务、计划任务占用。

默认策略：
- 按软件归类展示。
- 缓存、日志、临时文件可建议清理。
- 配置、数据库、用户资料默认保留。
- 软件仍在运行时提示关闭或跳过。

### 4.3 用户文件

定义：用户主动创建或下载的文档、图片、视频、项目文件等。

常见路径：
- 桌面
- 下载
- 文档
- 图片
- 视频
- 音乐

默认策略：
- 不纳入自动清理。
- 只做大文件提醒、重复文件提醒、长期未使用提醒。
- 删除前必须二次确认。

### 4.4 缓存与临时文件

定义：系统或软件运行时生成的可再生文件。

常见类型：
- `.tmp`
- `.log`
- `.cache`
- crash dump
- installer cache
- browser cache
- update temp

默认策略：
- 可以作为主要清理对象。
- 区分“安全清理”和“谨慎清理”。
- 清理前记录来源和路径。

### 4.5 未知文件

定义：无法可靠判断来源、用途或风险的文件。

默认策略：
- 标记为“未知”。
- 默认不勾选。
- 给出进一步调查建议：查看数字签名、打开所在目录、搜索文件名、查看占用进程。

## 5. 风险等级

低风险：
- 临时目录文件。
- 已过期缓存。
- 崩溃日志。
- 软件更新残留包。
- 回收站内容。

中风险：
- 软件日志、旧版本备份、下载缓存。
- 卸载后残留目录。
- 大型重复文件。

高风险：
- 软件配置文件。
- 用户数据库。
- 浏览器 Profile。
- 游戏存档。
- 开发环境依赖目录。

禁止清理：
- Windows 核心系统文件。
- 驱动文件。
- 启动文件。
- 系统还原点目录。
- 正在被系统进程占用的关键文件。

## 6. 核心功能

### 6.1 系统盘扫描

功能说明：
- 自动识别系统盘。
- 支持全盘扫描、快速扫描、自定义目录扫描。
- 展示扫描进度、当前路径、已发现文件数量、预计可清理空间。

扫描模式：
- 快速扫描：只扫描常见缓存、临时目录、日志目录。
- 深度扫描：扫描完整系统盘，但跳过系统保护目录中的不可访问区域。
- 软件残留扫描：重点扫描卸载软件残留和 AppData。

### 6.2 文件来源识别

识别维度：
- 路径规则。
- 数字签名。
- 注册表安装信息。
- 文件元数据。
- 进程占用。
- 服务和计划任务引用。
- 文件哈希和本地规则库。

输出内容：
- 文件分类。
- 所属软件或系统组件。
- 风险等级。
- 推荐动作。
- 识别置信度。

### 6.3 清理建议

建议类型：
- 建议清理。
- 可选清理。
- 建议保留。
- 禁止清理。
- 需要人工确认。

每条建议包含：
- 路径。
- 文件数量。
- 占用空间。
- 来源。
- 删除影响。
- 是否可恢复。

### 6.4 清理执行

安全流程：
1. 用户选择清理项。
2. 工具生成清理预览。
3. 用户确认。
4. 工具创建清理快照。
5. 执行删除或移动到隔离区。
6. 输出清理报告。

删除策略：
- 低风险文件可直接删除到系统回收站或工具隔离区。
- 中风险文件默认进入隔离区。
- 高风险文件需要强确认。
- 禁止清理项不可选择。

### 6.5 隔离区与回滚

功能说明：
- 被清理文件可先移动到隔离区。
- 用户可在指定期限内恢复。
- 超过保留期后再永久删除。

默认设置：
- 隔离区保留 7 天。
- 最大占用空间 5 GB。
- 超过上限时提醒用户处理。

### 6.6 清理报告

报告内容：
- 本次扫描时间。
- 扫描范围。
- 文件分类统计。
- 清理前后空间变化。
- 已删除/隔离文件列表。
- 跳过项和原因。
- 风险提示。

## 7. 权限与安全设计

权限要求：
- 普通扫描使用普通用户权限。
- 扫描受保护目录时提示需要管理员权限。
- 删除系统相关路径文件时必须进行权限拦截。

安全机制：
- 系统目录保护名单。
- Microsoft 签名文件保护。
- 正在运行文件保护。
- 清理前快照。
- 清理日志不可静默关闭。
- 未知文件默认不处理。

高风险限制：
- 不提供“强制删除系统文件”入口。
- 不自动删除注册表关键项。
- 不自动删除驱动。
- 不自动删除用户 Profile。

## 13. 交互状态说明

按钮状态：
- Start Scan：扫描前可用，扫描中变为 Pause / Stop。
- Clean Selected：没有选择可清理项时禁用。
- Quarantine：中风险项默认推荐。
- Restore：隔离区选择文件后可用。

文件选择规则：
- 低风险项默认勾选。
- 中风险项默认不勾选。
- 高风险项默认不勾选，并显示警告。
- 保护项不可勾选。
- 未知项不可批量勾选。

提示文案：
- “系统保护文件已自动排除。”
- “未知文件建议先检查来源，不建议直接清理。”
- “清理前将创建恢复快照，可在隔离区恢复。”

## 14. 技术实现建议

Windows 侧能力：
- 使用 Win32 API 获取文件属性、占用状态、ACL 权限。
- 使用 Authenticode 验证数字签名。
- 读取注册表卸载项识别软件安装信息。
- 使用 Windows 服务和计划任务信息判断文件引用。
- 使用 Volume Shadow Copy 或工具隔离区实现恢复能力。

规则引擎：
- 路径规则。
- 签名规则。
- 文件类型规则。
- 软件来源规则。
- 时间和大小规则。
- 用户白名单规则。

建议的数据结构：

## 15. 主要风险

误删风险：
- 通过保护规则、隔离区、二次确认、清理报告降低。

识别错误：
- 通过置信度、未知分类、人工检查入口降低。

权限风险：
- 尽量使用普通权限扫描，仅在必要时请求管理员权限。

用户误操作：
- 高风险项默认不勾选。
- 不提供一键清理所有文件。
- 删除前展示影响说明。
