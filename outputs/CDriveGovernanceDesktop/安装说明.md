# MYL系统盘检测工具安装说明

## 推荐使用方式

1. 完整解压压缩包，不要只复制单个 EXE。
2. 打开文件夹中的 `MYL系统盘检测工具.exe`。
3. 如果需要扫描更多系统目录，右键选择“以管理员身份运行”。

## 创建快捷方式

双击或右键运行 `创建快捷方式.ps1`，脚本会在：

- 桌面
- 开始菜单

创建 `MYL系统盘检测工具` 快捷方式。

如果 Windows 阻止脚本运行，可以右键 PowerShell，进入本目录后执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\创建快捷方式.ps1
```

## 升级注意

升级时建议完整替换程序文件，但保留以下目录：

- `sdc-data`
- `reports`
- `quarantine`
- `web\data.json`

这些目录包含扫描结果、隔离记录、报告和本地规则。

## 卸载方式

当前版本是文件夹版：

1. 删除桌面快捷方式。
2. 删除开始菜单快捷方式。
3. 删除程序文件夹。

如果你希望保留清理记录和隔离恢复能力，请先备份 `sdc-data`、`reports`、`quarantine`。

## 可信说明

- 工具默认只分析，不自动删除。
- 安全清理需要二次确认。
- 清理项先进入隔离区，可恢复。
- Windows 系统组件只给官方处理建议。
- 当前为开发版，正式对外分发前建议做代码签名。
